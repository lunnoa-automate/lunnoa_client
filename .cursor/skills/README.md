# Cursor skills (mirrors)

Canonical skill files live in [`skills/`](../../skills/) at the package root
(published with `@lunnoa/client`).

This folder mirrors those skills so Cursor can load them while working in this
repo. When you edit a skill, change **`skills/<name>/SKILL.md`**, then copy it
here (or keep both in sync).

| Skill | Role |
|---|---|
| `lunnoa-solution-design` | BA / vibecoder interview → build brief |
| `lunnoa-client` | Engineer: auth, discover, define*, deploy, React hooks |

After `npm install @lunnoa/client`, copy from
`node_modules/@lunnoa/client/skills/` into your app’s `.cursor/skills/` (or
Claude Code skills path). See Lunnoa Docs → Develop → TypeScript client →
**For agents**.
